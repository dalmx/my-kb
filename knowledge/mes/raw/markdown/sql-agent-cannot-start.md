# SQL Server Agent 代理服务无法启动（启动后自动关闭）排查与解决

> SQL Server Agent 服务无法启动或启动即自动关闭的排查手册：绝大多数是账户/权限问题（登录账户被禁用/密码失效、内置账户权限不足），给出三条解决路径（改用管理员本账户、启用被禁账户、两者结合）与排查清单、关键位置速查。维护计划/定时备份/作业停摆时先查本文。

## 一、现象

SQL Server Agent 代理服务无法启动，或**启动后立即自动关闭**，常见报错提示账户/权限相关错误。

后果：依赖 Agent 的**维护计划、定时备份、作业（Job）**全部停止运行。

## 二、根因

绝大多数情况是**账户/权限问题**，两类原因：

| 原因 | 说明 |
|------|------|
| Agent 服务登录账户被禁用/密码失效 | 安全整理时误禁了 Agent 使用的 SQL 账户，服务无法用该账户登录 |
| 登录身份配置为内置账户但权限不足 | 用 Network Service 等内置账户运行，无权访问数据库资源 |

## 三、解决方法

### 方法一：改用管理员本账户 + 重新输入密码

1. **打开 SQL Server 配置管理器**
   - 开始菜单找「SQL Server 配置管理器」
   - 找不到则：我的电脑 右键 → **管理** → **服务和应用程序** → **SQL Server 配置管理器**
   - 选中 **SQL Server 服务**

2. **找到 SQL Server Agent，右键 → 属性**
   - 切到「登录」选项卡

3. **登录身份改为「本账户」，输入管理员账户和密码**
   - 选择「本账户」，填入管理员账户名和密码

4. **若服务被禁用，在此处改为「自动」启动**
   - 切到「服务」选项卡，启动模式选「自动」

5. **下拉列表显示异常的处理** ⚠️
   - 若点开下拉框只有一个很窄的列表、**看不到文字无法选中**：
   - 点击下拉后，用**键盘上下箭头**切换选项，按**回车**选中。
   - 这是配置管理器 UI 在某些系统上的渲染 bug。

6. 设置完成后，重新启动 SQL Server Agent 服务，应能正常启动。

### 方法二：启用被禁用的 Agent 账户

适用于：此前做过账号安全整理，把 Agent 使用的账户禁用了。

1. **查看 Agent 服务当前使用的账户**（配置管理器 → Agent 属性 → 登录，看「本账户」里填的是谁）
2. **到 SQL Server 的「安全性 → 登录名」里找到该账户**
3. **启用该账户**（右键 → 属性 → 状态 → 启用登录）
4. 重新启动 Agent 服务，启动成功。

> 典型场景：前几天因安全整理禁用了一批账号，今天发现 Agent 配的备份计划没按时运行——经查是 Agent 账户被禁了。

### 方法三：两者结合（终极手段）

若方法一、二单独都不好用，**将方法二中的账户密码改为管理员账户和密码**——即让 Agent 用管理员账户运行，同时确保该管理员账户处于启用状态。

## 四、排查清单

遇到 Agent 启动失败，按顺序检查：

- [ ] 配置管理器里 Agent 的「登录身份」是内置账户还是本账户？
- [ ] 若是本账户，该账户密码是否正确/是否过期？
- [ ] 该账户在 SQL Server 登录名里是否被禁用？
- [ ] 该账户是否有 `sysadmin` 固定服务器角色（Agent 服务账户通常需要）？
- [ ] Windows 服务里 SQL Server Agent 的启动模式是否被改为「禁用」？
- [ ] 查看 Windows 事件查看器（应用程序日志）和 SQL Server 错误日志，确认具体报错。

## 五、关键位置速查

| 操作 | 路径 |
|------|------|
| 配置管理器 | 计算机管理 → 服务和应用程序 → SQL Server 配置管理器 → SQL Server 服务 |
| Agent 登录身份 | Agent 右键 → 属性 → 登录选项卡 |
| Agent 启动模式 | Agent 右键 → 属性 → 服务选项卡 → 启动模式 |
| 登录名启用状态 | SSMS → 安全性 → 登录名 → 对应账户 → 属性 → 状态 |

## 六、预防

- **做账号安全整理前**，先记录各 Windows 服务/SQL 服务使用的运行账户，避免误禁。
- Agent 服务账户应有专用账户（非共享），并记录在运维文档中。
- 定期检查 Agent 服务状态及作业运行历史，发现停摆及时处理。
- 维护计划/关键 Job 配置失败通知（邮件/告警），避免长时间无人发现。
